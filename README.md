# 플레이트 로그 (PLATE LOG)

개인용 운동 기록 웹앱입니다. 요일별 루틴을 불러와 세트를 기록하고, 휴식·버티기·EMOM 타이머, 원판 계산, 컨디션 메모, 통계, 루틴 편집까지 한 화면에서 처리합니다. HTML 파일 하나로 동작하며, GitHub Pages에 홈 화면 앱(PWA)으로 올려 두었습니다: **https://danggae.github.io/plate-log/**

## 파일

- `index.html` : 앱 전체 (HTML·CSS·JS 한 파일, 약 190KB). 브라우저에서 바로 열면 동작합니다.
- `manifest.webmanifest`, `icons/` : 홈 화면 앱 이름·아이콘(원판 모양)
- `sw.js` : 오프라인용 서비스 워커. https 주소(배포한 곳)에서만 등록되고, 로컬 파일이나 http 테스트에는 영향 없음
- 외부 의존성
  - Google Fonts: Barlow Condensed, IBM Plex Sans KR (없으면 시스템 글꼴로 대체)
  - three.js 0.169.0 (jsDelivr CDN): 애니멀플로우 3D 뷰어를 처음 열 때만 불러옴

## iPhone에 설치

1. iPhone **Safari**로 https://danggae.github.io/plate-log/ 를 엶
2. 공유 버튼 → **홈 화면에 추가**
3. 그다음부터는 **홈 화면 아이콘으로만** 엶. iOS는 홈 화면 앱과 Safari 탭의 저장 공간이 따로라서, Safari 탭에서 남긴 기록은 홈 화면 앱에 보이지 않음
4. 다른 기기에 쓰던 기록이 있으면 그쪽에서 설정 → '영상까지 저장'(영상이 없으면 '파일로 저장') 후, 홈 화면 앱의 설정 → 기록 불러오기로 옮김

- 한 번 열고 나면 인터넷 없이도 열림(3D 뷰어는 한 번 열어 본 뒤부터)
- 새 버전을 올리면: 앱을 열 때 뒤에서 받아 두고 **다음에 열 때** 적용. 바로 보려면 앱 전환기에서 앱을 완전히 닫았다가 다시 엶
- 운동 기록과 영상은 iPhone 안(localStorage·IndexedDB)에만 저장되고 GitHub에는 올라가지 않음. 앱을 지우면 기록도 지워지니 백업 알림이 뜨면 zip으로 저장해 둘 것

## 사용 흐름

홈 → 운동 시작(추천 루틴 · 내 루틴 · 자유운동) → 운동 준비(루틴 불러오기, 종목 추가·삭제·순서·세트/횟수/휴식 수정) → 운동 진행(종목별 한 화면, 마지막 세트 완료 후 휴식이 끝나면 다음 종목으로 자동 이동) → 운동 끝(요약·새 기록·컨디션 메모) → 저장 → 기록 달력에 표시 → 날짜를 눌러 그날 운동 다시 보기·수정·복사·다시 하기·루틴으로 저장

## 화면 구성

| 화면 | 내용 |
|---|---|
| 홈 | 진행 중 운동 이어하기, 새 기록 카드, 백업 알림, 오늘의 추천 루틴(요일별), 내 루틴 목록, 하단 자유운동 · 루틴 추가 |
| 운동 준비 | 운동 이름(자동: "11월 4일 저녁 운동"), 종목 목록 편집, 종목 검색·추가, 새 종목 만들기, 루틴 불러오기 |
| 운동 진행 | 경과 시간, 진행 바, 이전/다음, 종목 카드(세트·키패드·타이머·원판·동작 영상·3D·그날 메모), 끝내기 |
| 운동 끝 | 운동 시간·완료 종목·세트·볼륨, 새 기록, 미완료 종목 안내, 컨디션 메모, 저장/계속/삭제 |
| 기록 | 월 달력(루틴 색 점, ‹ › 이동), 날짜별 운동 목록, 지난 날짜 기록 추가 |
| 운동 상세 | 세트별 기록, 종목별 그날 메모(추가·고치기), 컨디션(여기서도 고치기 가능), 기록 수정, 요약 복사, 다시 하기, 루틴으로 저장, 삭제 |
| 통계 | 내 몸 100일, 종목별 그래프(최고 무게·추정 1RM·총 횟수 등, 표와 말풍선에 그날 메모) |
| 설정 | 루틴 편집(추가·삭제·색·종목), 요일별 추천 루틴, 내가 만든 종목, 종목 합치기, 원판, 백업(복사 · .json 파일 · 영상 포함 .zip) |

## 주요 기능

- **종목 타입 6가지**: 무게×횟수, 횟수, 버티기(초), EMOM, 애니멀플로우(루틴 A/B별 세트×횟수, 지난번과 번갈아 A/B를 고름), 시간(분)
- **하루 여러 번 운동** 기록 가능 (운동 단위 저장)
- **전용 숫자 키패드**: 덮어쓰기 입력, ±증감, 이전/다음 칸, "이 세트만 / 전체 세트"
- **타이머**: 세트 후 휴식 자동 시작, 종목 마지막 세트 뒤 휴식이 끝나면 다음 종목으로 이동. 휴식은 버티기 타이머처럼 화면 가득 원이 줄어들며 남은 시간을 세고, 아래로 밀면 아래쪽 작은 휴식 바로 내려감(바를 위로 밀거나 시간을 누르면 다시 크게). 세트 사이 휴식이 끝나면 다음 세트를 바로 누를 수 있게 작은 바로 내려옴. 크게·작게 어느 쪽에서나 −10초/+10초/건너뛰기(10초보다 적게 남았을 때 −10초는 바로 끝냄), 종목 카드의 휴식 칩에서 그 종목 휴식 시간을 10초 단위로 바꿈(10초~10분). 버티기는 3초 카운트다운 후 시작하고 종목별로 "목표에서 멈춤(자동 완료) / 최대로 버티기" 선택. EMOM 라운드 알림
- **휴식·라운드 알림**: 소리와 함께 화면 전체를 루틴 색으로 세 번 깜빡임(무음 모드·진동 없는 iPhone 대비, '동작 줄이기' 설정이면 한 번만 옅게). 화면을 안 보고 있을 때 끝났으면 1분 안에 돌아올 때 깜빡임
- **휴식 이어 하기**: 쉬는 동안 페이지가 닫혀도(iOS가 오래 쓰지 않은 탭을 정리) 다시 열면 운동 화면과 남은 휴식 시간이 그대로 돌아옴(크게/작게 보던 상태도). 닫힌 사이 휴식이 끝났으면 다음 종목으로 옮겨 둠(30분 넘게 지났으면 홈에서 시작)
- **타이머 이어 하기**: 버티기·EMOM·시간 타이머도 같은 방식. 진행 중이면 같은 시각 기준으로 다시 띄우고, 그사이 끝났으면 끝났을 시각으로 기록한 뒤 휴식도 그 시각부터 셈(EMOM은 전체 라운드, 버티기는 목표 초). '최대로 버티기'는 언제 멈췄는지 알 수 없어서 10분 안에 돌아왔을 때만 이어 감. 끝난 지 30분이 넘었으면 기록하지 않음
- **진행 관리**: 지난번 기록, 증량 버튼, 목표 미달 안내, 새 기록 알림
- **빈 횟수 ✓**: 횟수를 비운 채 ✓를 누르면 회색 안내 숫자대로 기록. 지난번과 같은 무게면 지난번 그 세트 횟수, 무게를 바꿨거나 기록이 없으면 목표 하한. 그래서 입력 없이 ✓만 눌러서는 증량 제안이 나오지 않고, 상한을 직접 입력해야 나옴
- **종목 메모(그날 그 종목에만)**: 운동 카드의 '+ 메모'로 적고, 그 운동 기록(`items[].en.memo`)에만 저장됨. 다른 날 같은 종목을 해도 빈 칸으로 시작하고, 루틴이나 종목 정의에는 들어가지 않음. 쓰는 중에 휴식이 끝나도 다음 종목으로 넘어가지 않음. 운동 상세에서 추가·고치기, 요약 복사와 통계 표에도 날짜별로 나옴. 종목 편집의 '고정 안내'(`ex.note`, 예: "좌우 각각")는 따로이며 매번 보임
- **종목은 이름이 아니라 종목 id로 묶음**: 통계·지난번 기록·증량 제안이 모두 같은 종목(id) 기준. 그래서 이름을 바꿔도 기록이 이어짐
- **같은 이름 확인**: 운동 준비의 '새 종목 만들기'나 루틴 편집의 '종목 추가'에서 이미 있는 이름(띄어쓰기·대소문자 무시)이면 '기존 종목 쓰기 / 따로 새로 만들기'를 물음. 종목 검색도 띄어쓰기를 무시함. 기존 종목 이름을 다른 종목과 같게 바꾸면 종목 합치기를 안내함
- **종목 합치기**(설정): 실수로 같은 운동을 두 종목으로 만들었을 때(이름이 달라도) '없앨 종목'의 기록을 '남길 종목'으로 옮김. 옮긴 기록의 종목 이름도 바뀌고, 없앤 종목은 루틴(그 루틴의 세트·횟수 설정은 유지, 이미 남길 종목이 있으면 뺌)과 내가 만든 종목에서 빠짐. 동작 영상은 남길 종목에 없을 때만 옮김. 기록 방식이 같은 종목끼리만, 애니멀플로우는 제외. 두 번 눌러 확인하고, 합친 직후 다른 것을 바꾸기 전까지 '방금 합친 것 되돌리기' 가능(새로고침하면 사라짐). 한 운동에 같은 종목이 둘이 되면 통계에서는 한 점으로 모아 보여 줌
- **세트 추가·삭제**: 운동 카드의 − 세트 / + 세트로 오늘만 세트 수를 바꿈(1~10, 좌우 종목은 한 쌍씩, 루틴은 그대로). 완료한 세트는 지우지 않음
- **원판 계산**, **동작 영상**(애니멀플로우는 루틴별), **3D 마네킹**

## 데이터 저장

- 기록·설정: `localStorage` 키 `platelog.v1` (JSON 하나, `v: 3`)
- 동작 영상: IndexedDB `platelog-media` → store `clips` (키: 종목 id, 애니멀플로우는 `aflow:A`, `aflow:B`)

### JSON 구조 (요약)

```json
{
  "v": 3,
  "workouts": {
    "wmhk2x1abc": {
      "id": "wmhk2x1abc",
      "date": "2026-11-04",
      "name": "11월 4일 저녁 운동",
      "routine": "S",                 // 불러온 루틴 키, 자유운동이면 null
      "status": "done",               // plan 준비 중, run 진행 중, done 저장됨
      "created": 1793797000000, "start": 1793797100000, "end": 1793800000000,
      "cur": 2,                       // 진행 중인 종목 위치
      "items": [
        { "u": "uab12cd",
          "ex": { "id": "fsquat", "name": "프론트스쿼트", "type": "weight", "n": 3, "lo": 5, "hi": 8, "inc": 5, "rest": 180, "bar": true },
          "en": { "sets": [ { "w": "80", "r": "8", "done": true, "t": 1793797200000 } ], "memo": "왼쪽 무릎 시큰" } }   // memo: 그날 이 종목 메모(없으면 키 없음)
      ],
      "memo": { "sleep": 4, "fatigue": 2, "pain": ["허리"], "text": "..." },
      "prs": [ { "txt": "프론트스쿼트 최고 무게 85kg", "d": "+5kg" } ]
    }
  },
  "active": "wmhk2x1abc",            // 진행 중 운동(없으면 null)
  "rest": { "w": "wmhk2x1abc", "end": 1793797350000, "next": "uab12ce", "from": "uab12cd", "start": 1793797260000, "mini": false },   // 진행 중 휴식(없으면 키 없음). next·from은 종목의 u, start는 원 비율 계산용 시작 시각, mini는 작은 바로 내려 둔 상태. 백업에는 넣지 않음
  "timer": { "mode": "hold", "w": "wmhk2x1abc", "u": "uab12cf", "i": 1, "t0": 1793797400000, "target": 30, "max": false, "title": "플랭크 · 2세트" },   // 진행 중 타이머(hold·emom·clock). t0은 3초 카운트다운 시작 시각. 백업에는 넣지 않음
  "routines": { "S": { "name": "근력", "sub": "...", "color": "red", "ex": [ /* 종목 정의 */ ] } },
  "dayMap": { "0": "X", "1": "S", "2": "P", "3": "C", "4": "S", "5": "P", "6": "X" },   // 요일별 추천, X는 휴식
  "custom": [ /* 사용자가 만든 종목 정의 */ ],
  "settings": { "rest": { "pullup": 120 }, "holdMax": { "plank": true }, "bar": 20, "plates": [25,20,15,10,5,2.5,1.25], "clip": {} },
  "challenge": { "start": "2026-11-03" },
  "prSeen": {}, "lastBackup": 1793600000000
}
```

- 각 운동의 `items[].ex`는 그날 쓴 종목 설정의 사본이라, 나중에 루틴을 바꿔도 지난 기록은 그대로 남습니다.
- 입력값(`w`, `r`, `s`)은 문자열입니다.
- 예전 형식(`sessions`, 날짜별 1개)은 열거나 불러올 때 자동으로 `workouts`로 변환됩니다.
- 열거나 불러올 때 `migrate()`가 형식을 검사합니다. 숫자 칸은 숫자로 바꾸고, id·루틴 키·색은 정해진 모양만 받으며, 형식이 맞지 않는 운동이나 종목은 버립니다. 불러오기는 모든 화면을 한 번 그려 본 뒤 문제가 없을 때만 바꿉니다.
- 저장된 JSON이 깨져 있으면 빈 데이터로 시작하기 전에 원본을 `platelog.v1.corrupt.<시각>` 키에 남깁니다. 저장에 실패하면(용량 부족 등) 알림을 띄웁니다.
- 지난 날짜를 나중에 입력한 운동은 `start`·`end`를 비워 둡니다. 입력한 시간이 운동 시간으로 잡히지 않게 하기 위해서입니다.

### 백업 (설정 → 기록 내보내기)

- **복사 / 파일로 저장**: 위 JSON만 (`platelog-YYYY-MM-DD.json`). 동작 영상은 빠짐
- **영상까지 저장**: zip 하나 (`platelog-YYYY-MM-DD.zip`, 압축 없이 저장, 파일 이름 UTF-8)
  - `platelog.json` : 위 JSON과 같음
  - `clips/index.json` : `{ "IndexedDB 키": { "file": "clips/…", "type": "video/mp4" } }`
  - `clips/<종목 이름>.<확장자>` : 영상 원본 (애니멀플로우는 `애니멀플로우 A.mp4`처럼 루틴별). 압축을 풀면 그대로 꺼내 쓸 수 있음
  - 영상을 읽고 CRC를 계산하느라 시간이 걸려서, 한 번 눌러 만들고 한 번 더 눌러 저장합니다 (휴대폰 공유 시트는 탭 직후에만 열림)
- 휴대폰(터치 화면)은 공유 시트(파일에 저장·AirDrop 등), 컴퓨터는 다운로드로 저장
- **불러오기**: 붙여 넣기, `.json`/`.txt`, `.zip` 모두 가능. zip은 폴더째 다시 압축한 것도 읽음(`__MACOSX` 무시, 압축된 항목은 `DecompressionStream`으로 풂). 기록은 통째로 덮어쓰고, 영상은 같은 키만 덮어씀(백업에 없는 영상은 그대로 둠)
- **불러오기 되돌리기**: 불러오기 직전 기록을 `platelog.v1.undo`(시각은 `.undoAt`)에 남기고, 덮어쓴 동작 영상은 IndexedDB `undo:키`로 옮겨 둠. 설정 → 기록 불러오기의 '불러오기 전으로 되돌리기'(두 번 눌러 확인)로 기록과 영상을 함께 되돌림. 불러온 뒤 한 기록은 사라짐. 7일이 지나거나 다음 불러오기를 하면 지워짐
